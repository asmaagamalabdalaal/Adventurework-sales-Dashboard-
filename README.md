# AdventureWorks Sales Dashboard

This repository contains the raw data and analysis for the AdventureWorks Sales Dashboard project.

## Data Structure

The dataset includes:
- Sales data from 2020-2022
- Customer information
- Product categories and subcategories
- Territory information
- Calendar lookup
- Returns data

### Files Organization
- AdventureWorks Calendar Lookup
- AdventureWorks Customer Lookup
- AdventureWorks Product Categories Lookup
- AdventureWorks Product Lookup
- AdventureWorks Product Subcategories Lookup
- AdventureWorks Returns Data
- AdventureWorks Sales Data (2020-2022)
- AdventureWorks Territory Lookup

## Data Sources
The data is structured in CSV format and includes comprehensive sales, customer, and product information from the AdventureWorks database.

## Purpose
This data is used to create insightful sales dashboards and analysis to track business performance and identify trends across different dimensions like products, territories, and time periods.
